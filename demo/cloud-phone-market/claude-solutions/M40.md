## Mistake restated
Region pickers list HK/SG/TH/JP as capacity labels only. The user picks blind, gets 180 ms RTT on a touch-heavy game, blames "cloud phone is laggy," and churns before session 2. Competitors persist because inventory teams sell whatever rack is free, and honest RTT numbers require probe endpoints at every edge.

## Strlix solution (concrete UX + IA)
**Probe before pick, inside the phone shell — not a settings page.**

1. **Silent pre-probe on market load.** On first paint of `/market`, fire parallel `HEAD /ping` (8-byte) against each region's edge probe, 3 samples, 400 ms budget each. Take median, discard max. Runs while the user browses the catalog, so zero added wait.
2. **Region chips carry live numbers.** In the device card's region row: `SG 38ms ●● · HK 71ms ● · TH 112ms ○`. Colour bands: ≤60 green, 61–120 amber, >120 grey. Chip shows a spinner dot only if probe is still in flight; never a bare name.
3. **Fitness verdict per content type.** Each catalog item declares `latencyClass: touch|casual|batch`. The chip renders a one-line verdict computed client-side: "Good for this game" / "Playable, input may drift" / "Use for install & idle farming only". This is the AI-inside-the-phone surface: the in-phone assistant bubble says the same sentence when the user boots into an amber region, with a one-tap **Switch to SG** action that migrates the session.
4. **Sticky honesty.** If measured RTT drifts >40 ms above the number shown at purchase within the first 24 h, the in-phone notification offers a free region migration (no refund flow needed).
5. **IA:** region is an attribute *of the session start*, not a global account setting. Never a signup-step dropdown.

## Android 7+ / graceful degradation notes
- `fetch` + `AbortController` exist on Chrome 51+ (Android 7 stock WebView); fall back to `XMLHttpRequest` with `ontimeout` where absent.
- No `performance.getEntriesByType('resource')` dependency — measure with `Date.now()` deltas.
- If **any** probe fails or the whole batch times out: show `SG · capacity available` with a neutral dot and the text "Tap to test" (user-initiated retry). Never show a fabricated number, never block the buy button.
- Prefer `navigator.connection.saveData` → skip auto-probe, manual only.
- Chips degrade to a plain `<select>` with ms appended to option labels if flex-wrap layout breaks.
