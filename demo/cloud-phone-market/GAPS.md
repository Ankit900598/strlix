# Gaps (15–20) — things cloud phone apps are NOT doing well

Derived from RESEARCH.md + MISTAKES-50.md. Numbered for tracking.

1. **No instant try** — buy/wallet before first pixel (VSPhone-class).
2. **Opaque wallets** — balance without runtime estimate.
3. **Specs honesty** — listed apps/games look preinstalled but are not.
4. **Wrong default aspect** — non-phone shapes until manual swap.
5. **Fake latency meters** — constant ms displays.
6. **Session wipe on restart** — no snapshot restore.
7. **Web shell not Android-7-graceful** — assumes WebCodecs/modern Chrome only.
8. **Outside AI chat / RPA** — not in-phone assistant.
9. **No mini-entry → fullscreen** consumer delight (farms start as tables).
10. **RAM/ROM/Android filters incomplete** or buried.
11. **Payment opacity** — contact sales / surprise overage / now.gg-like confusion.
12. **A11y ignored** — unlabeled canvas, custom dropdowns, no focus order.
13. **Tools eclipse the phone** — device-farm chrome overload.
14. **No status/outage honesty** during disconnects.
15. **Browser sold as Android** — fingerprint-only confusion.
16. **Ads/queues on instant-play** — breaks trust (now.gg).
17. **No progressive identity** — force account before wow.
18. **Share links without expiry**.
19. **Local payment rails missing** (UPI/Razorpay) for growth markets.
20. **No public practice of AI-inside-phone** as category differentiator.

Strlix targets gaps 1,7,8,9,10,11,12,17,20 in the shipped web-market + market-api stubs.
