# Desktop wrapper (Tauri preferred)

Wrap `web-market` + phone viewer in Tauri 2 for macOS/Windows/Linux. Window aspect ≈ phone bezel; optional frameless.

```bash
# future
npm create tauri-app strlix-desktop
# point devUrl to http://127.0.0.1:8790 (web-market static server)
```

Electron acceptable fallback. Auto-update via GitHub Releases.
