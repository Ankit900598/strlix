Support

Last updated 22 September 2026 · Strlix soft launch

How to reach the operator

The support address is configurable. Set SUPPORT_EMAIL or STRLIX_SUPPORT_EMAIL on market-api. GET /v1/launch returns the address in use and support_email_placeholder.

This static page shows the default: support@strlix.app. The mailbox is being set up. Do not assume that address is monitored until /v1/launch reports the placeholder flag as false. This HTML does not read that setting; when the mailbox is real, update this page in the same change.

Write about access problems, waitlist removal, or a lease that did not start. Include the time and the email you used. Do not send passwords, card numbers, or session tokens.

Before you write

  • The first month is free. You should not be asked for a card. If a screen asks for one, stop and wait for a monitored mailbox. Live Stripe is off.
  • The phone on screen is a shared cloud Android (an emulator unless a physical phone is attached). The free month does not hold a private device for 30 days.
  • A live session lasts about an hour. After that, the same Android can be reused.
  • The in-phone AI can be wrong. It is not professional advice.
  • Read what Strlix can and can’t do before reporting a missing assistant or a latency number.

Where these pages live

On the public Front Door host the pages are /market/legal/terms.html, privacy.html, support.html, and capabilities.html. The phone host serves the same text at /static/legal/.

Status

GET /health on market-api reports pay_mode, whether the free month is active, and whether a card is required. It does not include secrets.
